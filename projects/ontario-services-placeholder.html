Architecture and approach

A staff-facing CFML application sits between the browser and SQL Server. Shared procedures keep reads and writes consistent for QA and support. JavaScript on the front-end handles progressive enhancement only — forms still submit without it.

CREATE PROCEDURE dbo.GetActiveRecords
    @Status nvarchar(32)
AS
BEGIN
    SET NOCOUNT ON;

    SELECT
        record_id,
        display_name,
        updated_at
    FROM dbo.Records
    WHERE status = @Status
    ORDER BY updated_at DESC;
END;
